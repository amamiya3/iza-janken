# 天秤の動き試作

2026-11-18。URL: https://amamiya3.github.io/iza-janken/prototypes/balance.html

- 勝ち/負け/あいこで動作。勝者側の皿が沈み、得点差で傾く。
- 魂の落下後に得点更新。ばねと減衰による腕の回転、皿の揺れ、光の波紋。
- requestAnimationFrame、時間差分と1/240秒以下の積分で60/120Hz画面の動作差を抑える。描画fps表示は参考測定で保証値ではない。
- 余韻スライダーで減衰調整、リセット可能。端末の動きを減らす設定に対応。
- 試作用SVG素材を使用。採用済みの美術素材への置き換えは未実施。
- 3点で停止するのは動作プレビュー用。ゲーム本体のルール確定・実装を意味しない。
- 通信、カード所持/消費、戦績保存に接続しない独立ページ。

検証: JS構文、複数目標角でのばね収束、得点方向と皿の位置関係の数値検証に成功。実ブラウザ/実機iPhoneの滑らかさは未検証。ユーザーが実機で操作して採否を判断する。
