# DEAD 簡易プレイ版

2026-11-18。ユーザーは50種の提案を実装ベースとし、重複・衝突は相談して詰めることを承認。デザイン仕上げより先に遊べる素体を優先。

## プレイ可能
- dead.html。ホームDEAD入場後のリンクからも入れる。
- CPUは通常3手をランダムに選び、カードは使わない。対戦相手のカード・手を事前に表示しない。
- 3点先取、3種まで装備、1局1枚、明示的に発動予約して手を確定すると消費。予約取消・閲覧・装備で消費しない。
- 実装カード20種：01,02,03,04,05,06,07,08,09,18,21,23,25,26,27,38,46,47,48,49。
- 条件付きカードは使用条件を表示。履歴に元の手・変化後の手・効果・得点を記録。
- 練習カードは各2枚。補充ボタンあり。専用保存キー souju-dead-practice-v1。既存の通常戦績・将来の本番所持とは完全に別。
- リロードや途中退出は練習試合を終了。消費済み枚数は保存。未確定予約は消費しない。

## この試作での処理
手の変化→通常勝敗→勝敗の書換え/局無効→得点変更/防止→次局封印→試合終了。CPUはカードを使わず、同時秘技の競合をまだ導入しない。
時戻しの局は無得点・局番号据置で再勝負。無効履歴は復讐/連続手判定から除く。消費した時戻しは戻さない。画面の得点は3で上限表示。これらは練習版の実行定義であり、未確定のオンライン競合仕様に流用しない。
挑発は手を選んだ後で発動予約し、予約中は変更不可。CPUは情報に反応しないランダム練習相手。
