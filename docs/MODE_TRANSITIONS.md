# ALIVE / DEAD 入場演出

2026-11-18 ユーザー指定。天秤とは無関係のホーム入場演出。

- ALIVE：ホームが暗いブラックホールへ縮みながら吸い込まれ、約2.85秒で通常対戦準備画面へ。
- DEAD：ホーム画面を石板の破片に分け、ひび割れ→落下→暗い階段を降りる視点。約5.1秒でDEAD準備画面へ。
- DEADの秘技対戦は未実装。制作中表示と通常ルールのデモ入口のみ。カード消費や報酬は追加していない。
- 合言葉入力は演出後の準備画面に維持。ALIVEから接続/ソロ、DEADから通常ルールのデモを選べる。
- 薄い黄緑の接触光、押下時の沈み込み、余光。選択手に黄緑の選択光を保持。
- 操作音は低域ノイズと短い衝撃で石板の乾いた響きを合成。従来の効果音ON/OFFに連動。勝敗効果音は維持。
- スキップボタン/Escape、連打防止、フォーカス移動、入力/スクロール復帰、復帰用タイムアウト、動きを減らす設定に対応。
- 描画はCanvas 2DとCSS transform、DPR上限1.5。ホームのパーツ画像をCanvasに重ね、崩落の素材として使う。階段は軽量な手続き描画。
